Entry for the [make.fun](https://make.fun) bounty **"The Robot Vacuum's Best Excuse"** — write the funniest one-line excuse (140 characters or fewer) a robot vacuum gives for missing a spot. A judge playing a tired homeowner compares the lines two at a time and picks the funnier one.

## The entry

> My cliff sensor saw the rug's shadow, panicked, and filed the whole corner as a staircase. I believed it.

(105 characters, one line.)

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the entry line to `/output/entry.txt` (creating `/output` if needed).
